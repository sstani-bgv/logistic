## 2.1 Модель — сделано

- `llm.complete(prompt, schema)`: `POST {LLM_BASE_URL}/chat/completions`, режим `LLM_JSON_MODE`: `json_object` (схема в system) или `json_schema`. Таймаут `LLM_TIMEOUT`, один повтор на таймаут, сеть, 429 и 5xx; 4xx — сразу ошибка. Ответ проверяется по схеме: пропущенные nullable-поля дополняются null, лишние отбрасываются. Ошибка → `summary` диалога.
- `llm_proxy.py` — локальный OpenAI-совместимый эндпоинт: `codex` (Codex CLI) или `mock`.
- Осталось: прогнать 15–20 реальных диалогов на YandexGPT, DeepSeek и Qwen. Критерии: не выдумывает факты, верно ставит ready/declined, цена.

## 2.3 Статус машины

- `trucks.status` free/busy (миграция `alter table`).
- Поиск: `active=1 and (status='free' or free_from <= today+2)` (`fleet.scan_filter`).
- PATCH диалога в `taken` → машина busy, `city_name` = город выгрузки, `free_from` = дата выгрузки; если её нет — погрузка + дни пути (дистанция / ~500 км в день).
- Фоновая задача: `free_from <= today` → free.
- UI: переключатель «Свободна» на карточке машины.

## 2.5 Логины и роли

- `users(id, login, password_hash, role, active, created)`, роли owner / logist; argon2 (`argon2-cffi`).
- Сессия: случайный токен в httpOnly cookie; в таблице `sessions` хранится sha256 от токена; срок 30 дней.
- Все `/api/*`, кроме входа, выхода, `/api/health` и вебхуков/голоса (у них свой вход), — только после входа. `/api/settings` (PUT) и `/api/users` — только owner.
- CLI: `uv run python manage.py create-owner <login>`, `reset-password <login>` (сбрасывает сессии).
- Автор ручных действий (отказ, правило, «взяли груз», ручное сообщение, звонок, настройки) — в журнал событий и в таблицу `actions`.
- UI: страница логина, управление пользователями, настройки скрыты для logist.

## 2.4 Деплой

- `Dockerfile` (uv + собранный web), `docker-compose.yml`: сервисы `app`, `caddy` (HTTPS), `backup`; `restart: unless-stopped`.
- `DATA_DIR=/data` для `data.db` и записей звонков → volume `data`. Демо-парк только при `DEMO_SEED=1` локально; на проде пусто.
- Бэкап: ежедневно в `BACKUP_AT` (МСК) `sqlite3 .backup` + проверка целостности → `/backups` и в S3 (Yandex Object Storage), хранение `KEEP_DAYS` (14). Ключи S3 — в `backup.env`, приложение их не видит.
- `.env` только на сервере.

## 2.2 Звонки

- Спайк первого дня: может ли ВАТС МегаФон отдать голос боту.
- Основной путь (план, не проверено): сотрудник-бот с SIP-аккаунтом в ВАТС; голосовой сервис регистрируется как SIP-клиент; исходящий — командой API ВАТС от сотрудника-бота; события и записи — вебхуками ВАТС. Запасной: SIP-транк ВАТС напрямую в бота.
- Голос: Yandex AI Studio Realtime API (`speech-realtime-max-tts-live`): модель сама слушает и говорит, перебивание — server VAD. Релей `server/voice.py`: звук ⇄ релей ⇄ Realtime. Сейчас с другой стороны браузер (тестовый звонок); для ВАТС — SIP-линия, события те же. Ключ Yandex AI Studio подключён (проверен запросом списка моделей).
- Тестовый звонок: до `VOICE_CALL_SEC` (240 с), дневной потолок `VOICE_RUB_DAY` (50 ₽). Расшифровка не попадает в переписку.
- Промпт: одно ядро (`agent.CORE`: только узнать недостающее, ничего не покупать, не подтверждать, не соглашаться) + блок канала (`CHAT` / `VOICE`). Цель переговоров выбирает логист; готовые сценарии правит владелец в «Настройках».
- Инструкции на звонок — `agent.call_instructions()`. После звонка: запись, расшифровка → сообщение `kind='call'` в переписке → `agent.negotiate()` обновляет facts/summary/status.
- Данные: таблицы `calls`, `do_not_call`, колонка `messages.kind`. Настройки: `call_enabled` (по умолчанию выключено), `call_after_min` = 15, `call_hours` = 09:00–19:00 МСК, `call_daily` = 20.
- Лимиты: один номер — не чаще раза в 2 часа; по грузу — не больше 2 реальных попыток и не больше 4 автоматических всего (включая неудачные); после любой попытки по диалогу — 30 минут до автоповтора. Звонок без итога дольше 20 минут закрывается сам. `CALL_LINES` — одновременных звонков (по умолчанию 1).
- Телефон: `firm.contacts[].phones[]` из выдачи АТИ. Если заказчик скрыт (нет `firm`), чата и звонка нет.
- UI: звонки в диалоге с записью и расшифровкой, «Позвонить сейчас», «Не звонить», стоп-лист в «Настройках».

## Нужно от клиента

- VPS: адрес и SSH-доступ, домен (или `<ip>.sslip.io`).
- ВАТС МегаФон: доступ к API, API-ключ, номер для исходящих, сотрудник-бот (логин и SIP-аккаунт).
- ATI: токен клиента вместо тестового (сейчас тестируем на токене интегратора, он действует до 19.11.2026); тариф с API мессенджера и поиска (проверяет `manage.py check-ati`).
- Yandex Cloud: бакет Object Storage для бэкапов (ключи — в `backup.env`).
- Список машин и сотрудников с ролями.
- Логист на 1–2 часа для инструктажа.
