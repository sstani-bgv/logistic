# Logistic — AI-диспетчер для ATI.su

Прототип: ищет грузы на ATI.su под свои машины, скорит их (`server/scoring.py`), отсеивает лишнее и ведёт переговоры с заказчиком в мессенджере ATI через ИИ-агента (`server/agent.py` → `server/llm.py`: любой OpenAI-совместимый API со structured output). Объяснения логиста агент превращает в правила (база знаний).

- `server/` — FastAPI + SQLite: ATI (`ati.py`), модель (`llm.py`, `agent.py`), скоринг (`scoring.py`), машины (`fleet.py`), логины (`auth.py`), звонки (`calls.py`, `telephony.py`, `voice.py`), служебные команды (`manage.py`)
- `web/` — React 19 + Vite + Tailwind + shadcn/ui: Грузы, Переговоры (канбан/диалоги, звонки), База знаний, Машины, Настройки, Сотрудники
- `deploy/` — Caddy, бэкапы, [инструкция по деплою](deploy/DEPLOY.md); памятка логиста — [docs/ПАМЯТКА.md](docs/ПАМЯТКА.md); план — [docs/PLAN.md](docs/PLAN.md)

## Запуск

Нужны `uv`, `pnpm` и токен ATI. Модель — любой OpenAI-совместимый API (Yandex Cloud, DeepSeek…), задаётся в `.env`.

```bash
cp .env.example .env   # вписать ATI_CLIENT_ID, ATI_TOKEN и блок LLM_*
(cd web && pnpm install)
./run.sh               # http://127.0.0.1:8010
```

Первый вход: `cd server && uv run python manage.py create-owner <логин>` (пароль спросит).

## Включение агента

На новой базе агент выключен: ни переписки, ни звонков. Переключатели — в «Настройках» или командой:

```bash
cd server && uv run python manage.py agent status|on|off   # отправка сообщений и автозахват грузов
cd server && uv run python manage.py calls status|on|off   # звонки; agent on их не включает
```

## Модель (LLM)

Приложение ходит только в `LLM_BASE_URL/chat/completions`; провайдер меняется в `.env` без правки кода (примеры — в `.env.example`).

Для разработки есть локальный OpenAI-совместимый эндпоинт `server/llm_proxy.py` (порт 8011, `run.sh` поднимает его сам, если задан `LLM_PROXY_MODE`):

- `LLM_PROXY_MODE=codex` — ответы через Codex CLI (`npm i -g @openai/codex`, затем `codex login`);
- `LLM_PROXY_MODE=mock` — мгновенные ответы по схеме, без сети и ключей.

Таймаут `LLM_TIMEOUT`, один повтор на таймаут/сеть/429/5xx, 4xx — сразу ошибка; ответ не по схеме — ошибка в summary диалога.

Выбор модели: `cd server && uv run python eval_models.py --label <имя> [--from-db]` — 15 сценариев и реальные диалоги, где логист поставил итог; проверяет выдуманные факты, ready/declined, запрет подтверждать от имени компании, время. Отчёт — `eval-<имя>.md`. Запустить с `.env` каждой модели и сравнить.

## Звонки и голос

- `TELEPHONY` пусто или `off` (по умолчанию) — звонков нет. `mock` — имитация для разработки: расшифровки помечаются как выдуманные. `megafon` — ВАТС МегаФон: нужны `MEGAFON_API_URL`, `MEGAFON_API_KEY`, `MEGAFON_BOT_USER` и `TELEPHONY_WEBHOOK_SECRET` (не короче 32 символов).
- Голос (`server/voice.py`, Yandex AI Studio Realtime): `YC_FOLDER_ID` и `YC_API_KEY`. Без них нет кнопки тестового звонка в диалоге.
- Подробнее про сервер — [deploy/DEPLOY.md](deploy/DEPLOY.md).

Проверка доступа к АТИ на токене клиента: `cd server && uv run python manage.py check-ati`. Состояние систем (АТИ, модель, телефония, бэкап) — в поле `health` ответа `/api/stats` и в плашке интерфейса.

## Памятка логиста

**Что делает ассистент.** Каждые 5 минут смотрит биржу АТИ под каждую свободную машину и отсеивает неподходящее. Когда агент включён, сам пишет заказчикам по лучшим грузам, а если в чате молчат — звонит (если звонки включены). Решение «берём / не берём» всегда за вами: агент ничего не подтверждает от имени компании.

### Первые дни

Сначала агент выключен: ассистент ищет и оценивает грузы, но заказчикам не пишет и не звонит (вверху висит плашка). Осмотритесь:

- поручите агенту пару грузов кнопкой «Поручить агенту» на странице «Грузы» — он подготовит черновики, их видно в «Переговорах», отправить можно вручную;
- если в окне диалога есть кнопка «Тестовый звонок: вы — заказчик», попробуйте её.

Когда всё устраивает, владелец включает агента в «Настройках».

### Каждый день

1. **Машины.** Утром проверьте переключатель «Свободна» на каждой карточке. Занятая машина — укажите в карточке, где и когда освободится. Под занятые машины грузы не ищутся (кроме тех, что освобождаются в ближайшие 2 дня).
2. **Переговоры.** Колонка «Готово — звонить» — агент выяснил главное (ставка, адрес, время). Откройте диалог, прочитайте факты и расшифровки звонков, позвоните и подтвердите сами.
3. **«Берём»** — машина автоматически станет занятой до даты выгрузки в городе выгрузки. Если дата или город неточные — поправьте в карточке машины.
4. **«Отказ»** — диалог закрыт, агент больше не пишет.
5. **Черновик** (жёлтый блок в диалоге) — агент сам его не отправил: отправка выключена или ответ похож на обещание («подтверждаем», «берём»). Отправьте его или поправьте.

### Учим агента

- В «Грузах» нажмите «Не то» и **напишите причину своими словами** («кирпич не возим — бьётся тент», «эта фирма платит через 60 дней»). Агент превратит её в правило и больше такие грузы не покажет или понизит.
- Правила видны в «Базе знаний», их можно выключить или удалить.

### Звонки

- Агент звонит, только если в чате нет ответа 15 минут, с 09:00 до 19:00 МСК, не чаще раза в 2 часа на номер, не больше 2 попыток по одному грузу и с паузой 30 минут между попытками.
- Если в чате заказчика нет, а телефон есть — звонок ставится сразу.
- Звонки включаются отдельно от переписки. Пока телефония не подключена, звонков нет — «Позвонить сейчас» покажет причину.
- В диалоге видны все звонки: запись, длительность, стоимость, расшифровка.
- «Позвонить сейчас» — позвонить сразу, даже если звонки выключены. Окно звонков, лимиты и стоп-лист действуют.
- «Не звонить» — номер уходит в стоп-лист. Если в разговоре попросили не звонить, номер попадает туда сам.
- «Тестовый звонок: вы — заказчик» — агент звонит вам в браузере голосом по сценарию этого диалога, вы играете заказчика. Так можно послушать, как он говорит. Заказчику ничего не уходит, расшифровка в переписку не попадает — она только показывается после разговора.

### Если что-то не так

- Агент пишет не то — выключите «Агент отвечает сам» в диалоге (звонки по этому диалогу тоже остановятся) и пишите вручную.
- Жёлтая плашка «Нет связи с сервером» — данные на экране могут быть устаревшими, обновите страницу.
- Вас выкинуло на страницу входа — сессия истекла, войдите снова.
- Настройки (лимиты, звонки, сотрудники, сценарии) видит только владелец.
